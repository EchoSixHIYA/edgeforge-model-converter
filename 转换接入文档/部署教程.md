# EdgeForge 模型转换工作台部署教程

本文用于在另一台 Windows 电脑上部署当前转换工作台。项目使用 WSL2 Ubuntu 22.04，Windows 侧只负责打开网页，数据和代码仍由 WSL 管理。

## 一、准备环境

在 Windows PowerShell 中安装并启动 WSL2 Ubuntu 22.04：

```powershell
wsl --install -d Ubuntu-22.04
```

首次进入 Ubuntu 后，确认项目目录，例如：

```bash
ls /workspace/model-converter
```

如果项目放在 Windows 的 E 盘，推荐映射为：

```bash
sudo mkdir -p /workspace
sudo ln -s /mnt/e/边缘部署/模型转换服务器 /workspace/model-converter
```

Windows 文件管理器显示这个入口为“文件”是正常现象，因为它是 Linux 符号链接；真正的项目目录仍是 Windows 路径下的文件夹。

## 二、安装项目环境

在 Ubuntu 22.04 中执行：

```bash
cd /workspace/model-converter
bash scripts/setup_wsl.sh
```

脚本会创建 Python 3.10 项目虚拟环境并安装工作台依赖。以后正常启动不需要重复安装。

算能 BModel 转换还需要 TPU-MLIR：

```bash
bash scripts/setup_sophon.sh
```

该脚本会准备 `vendor/sophon-demo` 并检查 `model_transform.py`、`model_deploy.py`。如果机器尚未安装官方 TPU-MLIR，请先按算能版本对应的官方安装说明进入 TPU-MLIR 环境，再启动工作台。

## 三、启动网站

```bash
cd /workspace/model-converter
bash scripts/start_wsl.sh
```

Windows 浏览器访问：

```text
http://localhost:5000
```

健康检查地址：`http://localhost:5000/health`。

如果 5000 端口已被占用，可换端口：

```bash
PORT=5001 bash scripts/start_wsl.sh
```

然后打开 `http://localhost:5001`。

## 四、提交一次转换

在页面中依次选择：

1. 芯片厂家：Rockchip 或 Sophon；
2. 目标芯片，例如 `RK3588`、`BM1684X`；
3. 模型架构；
4. 精度；
5. 上传原始训练权重。

算能 INT8 任务还需要上传校准图片 ZIP。网站只接受目录声明的原始权重格式，不接受用户上传预转换 ONNX 绕过专用导出器。

## 五、部署生成的 SDK 到板端

以 Sophon BModel SDK 为例：

```bash
unzip lprnet_bm1684x_f16_sdk.zip -d lprnet_sdk
cd lprnet_sdk
python3 -m venv --system-site-packages .venv
.venv/bin/pip install --no-deps .
.venv/bin/python example.py
```

板端需要提前安装与芯片匹配的官方 `sophon.sail`。RKNN SDK 则使用包内的 `install.sh` 安装 RKNNLite 运行时。

SDK 的显式调用形式如下：

```python
from edgeforge_sdk import LPRNet

with LPRNet("model") as model:
    result = model.predict("plate.jpg")
    print([item.as_dict() for item in result])
```

不要把官方 `reference/` 示例当作 SDK 主入口；它们只用于对照验证。

## 六、常用检查

```bash
python -m pytest -q
python scripts/smoke_bmodel.py path/to/generated_sdk.zip
```

板端验收时，使用板端项目虚拟环境运行 SDK，并使用 `bmrt_test` 或 RKNNLite 确认模型能实际加载和推理。

## 七、更新项目

从私有 GitHub 仓库取得代码后：

```bash
git clone git@github.com:<你的账号>/<私有仓库>.git
cd <仓库目录>
```

以后更新：

```bash
git pull
bash scripts/setup_wsl.sh
```

不要提交 `data/tasks/` 下的大型任务产物、板端虚拟环境或本地密钥。模型权重和 BModel 应通过工作台任务产物或独立制品存储分发。
