导入本机模型目录

直接读取服务所在电脑的模型，不经浏览器上传大权重

请先在启动服务的电脑上用 EDGEFORGE_MODEL_ROOTS 配置允许导入的模型根目录。仅接受该根目录内的模型，并仅开放给本机回环访问；不提供任意文件系统浏览。WSL / Docker 请填写服务内部可见的路径，而非浏览器电脑的路径。

目录须包含完整配置、tokenizer / processor 与权重分片；只有配置文件不能转换。此入口不受浏览器 4GB 上传限制，也不会下载缺失权重或执行模型目录中的自定义代码。

LLM 编译预算

参数会参与预检，并随任务保存

先用小预算验证

像素预算用于每张图像或每个视频时序组（2 帧），并非整段视频的固定帧数限制。视频全部视觉 token 加上提示词、时间戳和生成内容仍须容纳在上下文内；运行时应明确设置采样帧数 / fps。实验阶段编译并发数锁定为 1，避免并发抬高主机内存峰值。预检仅提供估算，不能保证编译成功或板端性能。

✓

成功编译后交付完整 SDK 包失败任务只提供错误与日志，不会伪造 BModel 或 SDK 成功产物。
